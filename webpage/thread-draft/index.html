How do embodied agents generalize? By reusing skills. Manipulation varies across objects and scenes but shares a few skills: wiping a table or a window is one skill.

But an agent can only use skills it knows. Can VLMs build reusable skills from streaming experience?

🧵… Video2Skill: From Streaming Experience to Reusable Embodied Skills

Today, VLMs mostly label videos one at a time. Each video gets its own labels, and nothing carries over. But agents need one shared library of reusable skills, built up as experience streams in.

People learn this way. As we watch, we spot a skill we already know or pick up a new one, and we reuse it later. We ask: can VLMs do the same?

Jianshu Zhang @your_handle2/7 · The task426 chars · folds

The task in detail. For every action in the video stream, the model must:
1) find when the action happens,
2) write it as a skill, like grasp(object, from),
3) decide if the skill is already in its library or is new.

The library carries over to the next video. So early choices… affect later ones.

Our benchmark has robot videos (DROID/RH20T) and kitchen videos (HD-EPIC). It has 12,429 checked labels across 48 action types.

Jianshu Zhang @your_handle3/7 · How we measure it848 chars · folds

How we score it. We ask three questions.

1) Did it find the actions?
• Coverage: the share of real actions the model finds in time.

2) Did it group them right? Skill names don't matter. We only check which actions share a skill. We look at every pair of actions:
• Pair… precision: of the pairs it put together, how many are really the same action. Low means it mixes different actions.
• Pair recall: of the pairs that are really the same action, how many it put together. Low means it splits one action into many skills.
• ARI: one overall grouping score. 100 is perfect. 0 is random.

3) Did it add and reuse skills at the right time?
• Create recall: when an action shows up for the first time, how often it adds a new skill.
• Reuse recall: when an action shows up again, how often it uses an existing skill.

Jianshu Zhang @your_handle4/7 · 发现 1：两种测试形式（joint / text-based），各自的弱点442 chars · folds

Finding 1: we test VLMs in two setups.
• Joint: the model watches the video and updates its library in one step.
• Text-based: the model first describes the video in words. Then it updates the library from that text.

Across 19 open models, both setups do poorly, and they fail… in opposite ways. Joint models mix different actions into one skill. Text-based models keep giving the same action a new name. The best ARI is only 27 out of 100.

A text-based model makes grasp, pick_up and grab for the same action. 19 open VLMs tested; best ARI is at most 27 out of 100; bigger models are not always better.

Jianshu Zhang @your_handle5/7 · 发现 2：为什么是这三种训练方式，它们的联系，以及各自帮到了什么1053 chars · folds

Finding 2: can training fix this? Both mistakes come from one choice: reuse a skill, or add a new one. That choice depends on what is in the library. So we tried three ways to train. Each one changes the library the model practices with.

A) Oracle-history SFT: practice with the… correct library. The model learns what counts as the same skill. Joint models mix fewer actions: of the actions they group together, 68% are really the same, up from 37%.

B) Counterfactual Library-state Rebalancing (CLaRe): in the correct library, each skill is added once and then reused many times. So the model rarely practices adding one. CLaRe removes the needed skill, so the model must add it. On kitchen video, joint models add a new skill for 40% of first-time actions, up from 29% with A.

C) On-policy correction: at test time, the model uses its own library, mistakes and all. So we train it on that library, and a teacher gives the right answer. Text-based models stop making so many new names: one now reuses a skill for 95% of repeated actions, up from 29%.

Alt text

Animated explainer: three ways to train, each with a different library. B, Counterfactual Library-state Rebalancing (CLaRe): the correct library rarely asks for a new skill, so a needed skill is removed and the model must add it; on kitchen video, 40% of first-time actions get a new skill, up from 29% with A. C, On-policy correction: train on the model's own library, mistakes included; a text-based model reuses a skill for 95% of repeated actions, up from 29%.

Jianshu Zhang @your_handle6/7 · 发现 3：仍然存在的挑战——会复用、不会新建（真实例子）542 chars · folds

Finding 3: a problem remains. Trained models reuse skills well, but rarely add new ones.

Example: someone shapes a potato-chicken mix into a ball. No skill fits yet. A trained joint model finds the moment, but calls it grasp(object, source): its skill for picking up an onion.…
This is common. Trained joint models reuse a skill for 97–99% of repeated actions. But they add a new skill for only 19–40% of first-time actions. So the library stops growing: 40 kitchen videos show 46 kinds of actions, but the library ends with about 21 skills.

Jianshu Zhang @your_handle7/7 · 结论 + 链接 + 致谢668 chars · folds

Takeaway: training teaches models to use the skills they already have. The hard part is knowing when none of them fits and a new skill is needed. That is how an agent keeps learning new skills from what it sees. We think this is the key problem to solve next.
