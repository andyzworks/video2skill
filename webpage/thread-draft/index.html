Jianshu Zhang @SterZhang1/7 · Main post1045 chars · folds

🤖 Reusing skills is one possible way for embodied agents to generalize. Manipulation varies but shares a few skills: wiping a table or a window is one skill. Many works give agents skills to plan with. But where do these skills, and their data, come from?

📼 Today, VLMs mostly… label videos one at a time, and nothing carries over. People don't learn that way. As experience streams in, we spot skills we know, add new ones, and reuse them later. This streaming setting matters, but it has received little attention.

🧠 VLMs may become the brains of embodied agents. So we ask: from streaming experience, can they find reusable skills and keep one consistent skill library?

🧵 Video2Skill: From Streaming Experience to Reusable Embodied Skills

Why it matters:
📈 It can label much more data for training agents.
🔁 It is planning in reverse. If a model can't find skills in what it has seen, how can it plan with them for something new?

🎯 The task. For every action in the video stream, the model must:
1️⃣ find when the action happens,
2️⃣ write it as a skill, like grasp(object, from),
3️⃣ decide: is this skill already in its library, or new?

📚 The library carries over to the next video, so early… choices affect later ones.

Jianshu Zhang @SterZhang3/7 · How we measure it811 chars · folds

📏 How we score it. Three questions:

1️⃣ Did it find the actions?
• Coverage: the share of real actions the model finds in time.

2️⃣ Did it group them right? Skill names don't matter. We only check which actions share a skill, over every pair of actions:
• Pair… precision: of the pairs it put together, how many are really the same action. Low = it mixes different actions.
• Pair recall: of the pairs that are really the same action, how many it put together. Low = it splits one action into many skills.
• ARI: one overall grouping score. 100 is perfect, 0 is random.

3️⃣ Did it add and reuse skills at the right time?
• Create recall: when an action shows up for the first time, how often it adds a new skill.
• Reuse recall: when an action shows up again, how often it uses an existing skill.

Alt text

Animated explainer of the scores on a toy example. Locate: coverage 2 of 3, the share of real actions found in time. Group: pour and place wrongly merged, giving pair precision 1/2 (grouped pairs truly alike), pair recall 1/1 (alike pairs grouped), ARI 57/100 (overall grouping, 0 = random). Decide: create recall 1/2 (first sightings given a new skill), reuse recall 1/1 (repeats given an existing skill).

🏷️ Text-based models (describe the video in words first) keep renaming the same action.

Jianshu Zhang @SterZhang5/7 · Finding 21050 chars · folds

🛠️ Finding 2: can training fix this?

Both mistakes come from one choice: reuse a skill, or add a new one. That choice depends on what is in the library. So we tried three ways to train, each with a different library to practice on.

A) Oracle-history SFT: practice with the… correct library. The model learns what counts as the same skill. Joint models mix fewer actions: of the actions they group together, 68% are really the same, up from 37%.

B) Counterfactual Library-state Rebalancing (CLaRe): in the correct library, each skill is added once and then reused many times, so the model rarely practices adding one. CLaRe removes the needed skill, so the model must add it. On kitchen video, joint models add a new skill for 40% of first-time actions, up from 29% with A.

C) On-policy correction: at test time, the model uses its own library, mistakes and all. So we train it on that library, and a teacher gives the right answer. Text-based models stop making so many new names: one now reuses a skill for 95% of repeated actions, up from 29%.

Jianshu Zhang @SterZhang6/7 · Finding 3527 chars · folds

🧱 Finding 3: trained models reuse skills well, but rarely add new ones.

🥔 Example: someone shapes a potato-chicken mix into a ball. No skill fits yet. A trained joint model finds the moment, but calls it grasp(object, source): its skill for picking up an onion.

📊 This is… common. Trained joint models reuse a skill for 97–99% of repeated actions, but add a new skill for only 19–40% of first-time actions. So the library stops growing: 40 kitchen videos show 46 kinds of actions, but the library ends with about 21 skills.

Jianshu Zhang @SterZhang7/7 · Takeaway and links684 chars · folds

💡 Takeaway: training teaches models to use the skills they already have. The hard part is knowing when none of them fits and a new skill is needed. That is how an agent keeps learning new skills from what it sees. We think this is the key problem to solve next.
