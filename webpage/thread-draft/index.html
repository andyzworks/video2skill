Jianshu Zhang @your_handle1/7 · Main post485 chars · folds

Manipulation tasks vary a lot, but they share a small set of skills. Wiping a table and wiping a window use the same skill. Embodied agents plan with skills to handle new tasks.

But an agent can only plan with skills it knows. Can VLMs learn skills just by watching videos?

🧵… Video2Skill

Finding skills in videos is the reverse of planning. It lets an agent gain skills over time. It also turns plain videos into labeled data for training future agents.

Jianshu Zhang @your_handle2/7 · The task435 chars · folds

The task: a model watches videos one by one. Each time it sees an action, it must:
1) find when the action happens,
2) write it as a skill, like grasp(object, from),
3) decide if the skill is already in its library or is new.

The library carries over to the next video. So early… choices affect later ones.

Our benchmark has robot videos (DROID/RH20T) and kitchen videos (HD-EPIC). It has 12,429 checked labels across 48 action types.

Jianshu Zhang @your_handle3/7 · How we measure it848 chars · folds

How we score it. We ask three questions.

1) Did it find the actions?
• Coverage: the share of real actions the model finds in time.

2) Did it group them right? Skill names don't matter. We only check which actions share a skill. We look at every pair of actions:
• Pair… precision: of the pairs it put together, how many are really the same action. Low means it mixes different actions.
• Pair recall: of the pairs that are really the same action, how many it put together. Low means it splits one action into many skills.
• ARI: one overall grouping score. 100 is perfect. 0 is random.

3) Did it add and reuse skills at the right time?
• Create recall: when an action shows up for the first time, how often it adds a new skill.
• Reuse recall: when an action shows up again, how often it uses an existing skill.

Finding 1: today's VLMs can't do this well. We tested 19 open models. The best ARI is only 27 out of 100 (0 is random). Bigger models are not always better.

They fail in two opposite ways:
• Joint models watch the video and update the library in one step. They mix different… actions into one skill (low pair precision).
• Text-based models first describe the video in words, then update the library. They keep making new names for the same action (low pair recall).

Alt text

Animated comparison of two kinds of models without training. A joint model puts pour under place, mixing different actions into one skill. A text-based model makes grasp, pick_up and grab for the same action. 19 open VLMs tested; best ARI is at most 27 out of 100; bigger models are not always better.

Jianshu Zhang @your_handle5/7 · Finding 2945 chars · folds

Finding 2: so we designed three ways to fine-tune them. The difference is which library the model sees during training. No method wins on every score. Each is good at something different (counted over 8 settings: 2 models × 2 model types × 2 datasets).

A) Oracle-history SFT:… train with the correct library. Best at keeping different actions apart. Top pair precision in 5 of 8. Top ARI for joint models in 4 of 4.

B) Counterfactual Library-state Rebalancing (CLaRe): keep the video, but edit the library. If we remove the skill it needs, it must add a new one. If we add a similar name for a different skill, its answer should not change. Best at finding actions: top coverage in 3 of 4 joint settings.

C) On-policy correction: train on the library the model built itself, mistakes included. A teacher gives the right answer at each step. Best at keeping repeats of one action together. Top pair recall in 5 of 8. Top reuse recall in 7 of 8.

Alt text

Animated explainer of three fine-tuning strategies, each with its own strength. A, Oracle-history SFT: practice on the correct library; keeps different actions apart. B, Counterfactual Library-state Rebalancing (CLaRe): same video, edited library, so removing a needed skill forces a new one and adding a similar name keeps the same answer; finds the most actions. C, On-policy correction: practice on the model's own library, mistakes included; keeps repeats together. A grid counts settings where each is best: coverage 0/3/1 of 4; pair precision 5/2/1; pair recall 1/2/5; ARI 4/2/2; create recall 6/3/2; reuse recall 0/2/7 of 8. No single strategy wins everywhere.

Jianshu Zhang @your_handle6/7 · Finding 3599 chars · folds

Finding 3: training helps a lot. So what is still hard? One decision: when to add a new skill.

Example: a model sees grating for the first time. It should add a new skill. But trained joint models usually reuse an old one.

• Actions seen before: 97–99% go to an existing… skill.
• Actions seen for the first time: only 19–40% get a new skill.
• The models do see new actions. Actions never seen in training are found 58–66% of the time, more often than familiar ones. But only 0–1 of about 10 get their own skill.
• In kitchen videos, 46 action types show up. The library stops at 21–22 skills.

Jianshu Zhang @your_handle7/7 · Takeaway and links857 chars · folds

Takeaway: models can learn to match an action to a skill they already have. With training, joint models' ARI goes from 19 to 60. But seeing that no skill fits is much harder. Even with CLaRe, which trains this exact choice, joint models add a new skill at most 40% of the time.…
This choice is how an agent gains new skills from what it sees. One overall score can hide it, so we measure it on its own. We think it is the key problem to solve next.
